# @plasius/game-multiplayer

Plasius authoritative game sessions and matchmaking package, under development.
Implementation is tracked in [Task #1](https://github.com/Plasius-LTD/game-multiplayer/issues/1),
under [site Feature #2387](https://github.com/Plasius-LTD/plasius-ltd-site/issues/2387).

This initial repository establishes the schema-baseline legal and governance
files. No npm package, production service or playable game is released here.
The implementation will enter through a protected pull request and reviewed CI.
Publication uses only main `.github/workflows/cd.yml` and `production`; first
registration remains operator-gated. Stored `arcade.multiplayer.enabled` stays
disabled and the site public launch barrier remains required.
